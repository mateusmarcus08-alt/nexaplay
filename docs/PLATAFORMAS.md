# Plataformas NexaPlay

Alvos desejados: Android celular/tablet, Android TV, Google TV, Fire TV/Fire Stick, TV Box, Windows PC/notebook, Samsung Tizen e LG webOS.

A interface compartilhada serve como base de protótipo. Cada plataforma exige adaptação, testes em dispositivo real e, quando aplicável, empacotamento e assinatura próprios. Players devem usar apenas streams próprios/licenciados/autorizados.
